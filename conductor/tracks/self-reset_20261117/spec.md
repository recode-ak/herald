# Самосброс агента — spec

Утверждено Нурболатом 2026-11-17 (обсуждение в сессии u7-school).

## Обзор

На границе фазы трека нужен сброс контекста (`/clear`), но агент не может набрать команду сам, а после сброса стоит и ждёт человека. Новое: `herald self <команда> [--message <текст>]` — агент сам набирает команду в своё окно tmux и после неё — сообщение, с которого чистый агент продолжит работу.

Время не угадывается: момент набора берётся из хуков Claude Code — `Stop` (ход закончен, поле ввода свободно) и `SessionStart` (`source`: `clear` / `compact` — сброс или сжатие завершены). Без хуков (pi и др.) — явная задержка `--delay`.

## Функциональные требования

### Терминал (`TmuxTerminal`)
1. Однострочный текст — как сейчас: Ctrl+U, `send-keys -l`, Enter. Многострочный — через буфер tmux вставкой (`paste-buffer -p`, bracketed paste), затем Enter: перевод строки не отправляет сообщение раньше времени.

### Сигналы хуков (`HookSignals`)
2. `herald hook` читает JSON хука из stdin (`hook_event_name`, `source`) и записывает метку `{ event, source, at }` для панели `TMUX_PANE` в `$XDG_STATE_HOME/herald/hooks/` (по умолчанию `~/.local/state/herald/hooks/`). Вне tmux, при неизвестном событии или битом JSON — ничего не делает. Всегда код 0 и пустой stdout: хук не должен мешать Claude Code (stdout `SessionStart` попадает в контекст).
3. Метка читается «не раньше момента t»: старые метки (прошлые ходы, прошлые сбросы) не срабатывают.

### Самосброс (`SelfReset`)
4. Режим хуков (по умолчанию): ждёт `Stop` после запуска → набирает команду → для `/clear` и `/compact` ждёт `SessionStart` с тем же `source` после набора → пауза 1 с → набирает сообщение (если есть). Для прочих команд — пауза 1 с после набора, затем сообщение.
5. Режим `--delay <с>`: команда набирается сразу (Claude Code ставит её в очередь), сообщение — через заданное время.
6. Срок ожидания каждого сигнала — `--timeout <с>` (по умолчанию 600). Сигнала нет — сообщение не набирается, человеку уходит `notify` с причиной (не настроены хуки, ход не закончился).
7. Набор — только в свою панель (`TMUX_PANE`); вне tmux — ошибка сразу. Команда — с `/`.

### CLI
8. `herald self <команда> [--message <текст>] [--timeout <с>] [--delay <с>]` — проверяет аргументы, запускает себя фоном отдельной сессией (`setsid`, переживает конец хода и Bash агента; лог — рядом с метками) и сразу печатает `{ ok: true, pane }`. `--foreground` — выполнить в текущем процессе (отладка).
9. `herald hook` — требование 2.

### Документы и настройка
10. `docs/model.md` — команды CLI; `docs/install.md` — хуки `Stop` и `SessionStart` в `~/.claude/settings.json`.
11. Автопилот (глобальный `AGENTS.md`), п. 5: на границе фаз — сброс через `herald self /clear --message "<с чего продолжить>"`.

## Вне рамок
- pi: у расширения herald есть `newSession` и `sendUserMessage` — самосброс там делается средствами pi, отдельно.
- Набор в чужие панели, произвольные клавиши.
