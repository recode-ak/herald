# Новое окно агента — итог

Завершён 2026-11-17.

- `herald spawn <каталог> [--prompt] [--tmux agents] [--timeout 60]` — Claude Code с каналом herald в новом окне tmux-сессии `agents`; каталог — внутри домашнего; задача — первым сообщением (после `--`: флаг канала забирает значения).
- Стартовые диалоги (доверие к папке, dev-канал) — по экрану, клавиша по положению курсора; потерянное нажатие повторяется (не чаще раза в секунду) — нашлось на живой проверке.
- Закрыть окно — указанием «закройся»: агент вызывает `herald self /exit`. Подсказки про `spawn`, `/exit` и самосброс — в инструкциях канала.
- Проверено вживую на Claude Code 2.1.326.

Следующий трек: `herald host` (демон машины, `systemd --user`) и команды бота `/new`, `/exit` — когда активных агентов нет; нужна выкатка сервера.
