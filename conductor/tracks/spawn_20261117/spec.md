# Новое окно агента — spec

Утверждено Нурболатом 2026-11-17 (сессия u7-school). Первый из двух треков: здесь — запуск через активного агента; второй — `herald host` (демон машины) и команды бота `/new`, `/exit`, когда активных агентов нет.

## Обзор

Нурболат далеко и хочет параллельного агента для другой задачи. Он пишет указание активному агенту, тот вызывает `herald spawn <каталог> --prompt "<задача>"`: в tmux-сессии `agents` открывается окно с Claude Code и каналом herald, задача уходит первым сообщением, новая сессия появляется в `/sessions`. Лишнее окно закрывается указанием «закройся» — агент вызывает `herald self /exit`.

## Функциональные требования

### Запуск (`AgentLauncher`)
1. Каталог: `~/…`, абсолютный или относительный (от текущего); после `realpath` — существующий каталог внутри домашнего (`HOME`). Иначе — ошибка, ничего не запускается.
2. Окно — в tmux-сессии `agents` (`--tmux <имя>`): нет сессии — `new-session -d`, есть — `new-window -d`; имя окна — имя каталога. Команда — без shell: `claude --dangerously-load-development-channels server:herald [-- <задача>]` (флаг канала забирает значения после себя, поэтому задача — после `--`). `claude` — полный путь из `PATH` вызывающего.
3. Стартовые диалоги Claude Code проходятся сами, по экрану панели (`capture-pane`): «Yes, I trust this folder» (по умолчанию выбран «No, exit») — Down, Enter; «I am using this for local development» — Enter. Готово — на экране баннер «Channels (experimental)». Не дождался за `--timeout` (по умолчанию 60 с) или окно закрылось — ошибка с хвостом экрана.
4. Вывод: `{ ok: true, pane, window, dir }`.

### Терминал (`TmuxTerminal`)
5. `screen()` — текст панели; `press(...keys)` — клавиши tmux (Down, Enter) без Ctrl+U.

### Канал и документы
6. Инструкции канала: человек просит открыть окно для другой задачи — `herald spawn`; просит закрыть это окно — `herald self /exit`.
7. `docs/model.md`, `docs/install.md`.

## Вне рамок
- Демон машины, команды бота `/new`, `/exit` — второй трек (нужна выкатка сервера).
