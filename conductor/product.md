# herald — продукт

## Начальная концепция

Посредник между ИИ-агентами и человеком через Telegram. Агент, который сам ведёт работу (трек), шлёт уведомления и статус, задаёт стратегические вопросы с вариантами и получает ответ, где бы человек ни был. Человек смотрит статус и пишет указания конкретной сессии.

## Пользователи

- **Человек** (сейчас — Нурболат): отвечает с телефона кнопкой или текстом, смотрит `/sessions` и `/status`.
- **Агенты:** Claude Code (основной, через channel), pi и любой агент с shell (через CLI).

## Принципы

- Один бот — все машины, агенты и сессии; Telegram опрашивает только сервер.
- Сервис доставляет, а не толкует: решения (в т. ч. по таймауту) принимает агент.
- Переносимость: новая машина — clone, `bun run link`, конфиг.
- Аналоги и почему свой: Claude Code Channels — только Claude и бот на сессию (используем как транспорт в Claude Code); Takopi/Untether — запускают агента из чата, другой сценарий; MCP `ask_human` — одна сессия, pi без MCP.
