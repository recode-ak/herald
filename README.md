# herald

Посредник между ИИ-агентами и человеком через Telegram: уведомления, статус, вопросы с вариантами и ответы, указания конкретной сессии. Один бот на все машины и агенты.

- **Сервер** — опрашивает Telegram, хранит сессии, вопросы и входящие (SQLite), HTTP API.
- **CLI `herald`** — для любого агента с shell (pi и др.): `notify`, `ask`, `decide`, `status`, `inbox`.
- **Channel для Claude Code** — сообщения из Telegram приходят прямо в сессию.

Установка — `docs/install.md` (появится в треке v1). Лицензия — MIT-0.
